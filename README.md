# 전자공학개론 기출 문제은행

서버와 설치 없이 `index.html`을 열어 실행하는 오프라인 문제은행입니다.

## 시작

- `index.html`: 문제풀이
- `review.html`: 이미지 잘림·분류·정답 검수
- 오프라인 파일 보안 정책이 엄격한 브라우저에서는 폴더에서 `python3 -m http.server 8765`를 실행하고 `http://localhost:8765`를 열어도 됩니다.

## 현재 데이터

- 시험 55개, 문제 1,100개: 국가직 2007–2026, 지방직 2009–2012·2022–2026, 군무원 2022–2026, 국회직 2009·2014–2025, 서울시 2014–2021
- 대분류는 `회로이론`, `전자회로`, `디지털 공학`의 3개이며, 실제 풀이 단위의 세분류 체계(v2)를 적용했습니다. 전자회로 초반 중분류는 `반도체특성`, `PN접합다이오드`, `정류회로`, `평활회로`, `리미터클램퍼`, `제너다이오드` 순서입니다. 반도체특성은 물성·캐리어·에너지대 등 기초 특성만 다루며, MOS·FET·BJT 소자 및 반도체 공정은 별도 중분류로 분리합니다.
- `직류회로 해석`, `회로망 정리` 같은 포괄 분류는 사용하지 않습니다. 노드 해석, 루프 해석, Y－Δ 변환, 테브난 정리, 노턴 정리, 최대전력 전달 등을 각각 독립된 중분류로 선택할 수 있습니다.
- 한 문제가 여러 개념에 걸치면 `classification.topics`에 복수 중분류를 저장합니다. 현재 161문제가 복수 중분류이며, 문제 선택 화면에서는 여러 중분류를 체크해 합집합(OR)으로 출제할 수 있습니다.
- 1,100문제 모두 분류가 확정되어 있으며 분류 현황은 `review/classification-report.json`에서 확인할 수 있습니다.
- 1,100문제 모두 공식 정답을 적용했습니다. 국가직·지방직은 사이버국가고시센터, 군무원은 국방부 일반군무원 채용, 국회직은 국회사무처, 서울시는 서울특별시 지방공무원 임용시험 정답표를 기준으로 합니다.
- 국회직과 2014년 서울시는 5지선다, 나머지 시험은 4지선다로 문제별 선지 수를 표시합니다.
- 공식 정답 원본 PDF는 `official-answers/`에 보관하며, 2012년 이전 국가직·지방직 정답은 공식 사이트의 연도별 정답 조회 화면을 출처로 기록합니다.
- 현재 정답 미확정 문제는 없습니다.
- 정답 미확정 전체 목록: `review/unresolved-answers.csv`, `review/unresolved-answers.json`
- 시험별 20문제 한장 검수표: `review/contact-sheets/`
- 자동 감지 이슈: `review/crop-review.csv`, `review/build-report.json`

## 재생성

`tools/update_official_answers.py`가 확인한 공식 정답 데이터를 문제은행 형식으로 반영하고, `tools/build_bank.py`가 PDF 렌더링, OCR, 문제별 PNG 잘림, 검수표와 JSON을 만듭니다. OCR이 문제번호를 잘못 읽은 항목은 `data/anchor_overrides.json`, 여러 열에 이어지거나 큰 여백 때문에 자동 자르기가 어려운 항목은 `data/crop_overrides.json`에 보정 이유와 함께 보관됩니다.

세분류를 다시 적용하려면 `python3 tools/reclassify_questions.py`를 실행합니다. 이미지 대조로 확정한 예외는 스크립트의 `ID_OVERRIDES`에 있고, 결과는 `data/classification_overrides.json`에도 저장되므로 문제 이미지를 재생성해도 분류가 유지됩니다. 브라우저에서 표시한 이미지 검수 결과는 로컬 저장소에 보존되며 JSON으로 내보낼 수 있습니다.
