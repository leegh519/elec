# 전자공학개론 기출 문제은행

서버와 설치 없이 `index.html`을 열어 실행하는 오프라인 문제은행입니다.

## 시작

- `index.html`: 문제풀이
- `review.html`: 이미지 잘림·분류·정답 검수
- 한 문제씩 풀기에서 `이전 문제` 버튼이나 브라우저 뒤로가기로 이전 문항을 확인할 수 있습니다. 선택한 답과 채점 결과는 유지되며, 돌아가서 보는 것만으로 풀이 횟수가 늘어나지 않습니다. 첫 문제에서 브라우저 뒤로가기를 누르거나 `조건 다시 선택`을 누르면 조건 선택 화면으로 돌아갑니다.
- 오프라인 파일 보안 정책이 엄격한 브라우저에서는 폴더에서 `python3 -m http.server 8765`를 실행하고 `http://localhost:8765`를 열어도 됩니다.

## 현재 데이터

- 시험 55개, 문제 1,100개: 국가직 2007–2026, 지방직 2009–2012·2022–2026, 군무원 2022–2026, 국회직 2009·2014–2025, 서울시 2014–2021
- 대분류는 `회로이론` 299문제, `전자회로` 538문제, `디지털회로` 263문제입니다. 인강 기준 분류(v3)로 각각 17개·24개·17개, 총 58개 중분류를 사용합니다.
- `기본소자`는 소자 특성·기초량을 다룹니다. `회로해석`은 저항 직병렬·합성저항·전압/전류분배·KVL/KCL·노드/루프해석을 포함합니다. 브리지·Y–Δ 변환은 별도로, 테브난·노턴·중첩·최대전력전달·전원변환 등은 `회로망 정리`로 묶습니다.
- 한 문제가 여러 개념에 걸치면 `classification.topics`에 복수 중분류를 저장합니다. 현재 150문제가 복수 중분류이며, 문제 선택 화면에서는 여러 중분류를 체크해 합집합(OR)으로 출제할 수 있습니다.
- 현재 58개 중분류 모두 해당 문제가 있습니다. 필터·선형시불변시스템·블록선도는 회로이론에 배치합니다. 기존 기출을 보존하기 위해 비정현파·푸리에급수와 전계·자계·전자유도를 보충 주제로 유지합니다. 이전 분류와의 대응 및 문항 이동은 `review/curriculum-migration.json`에 기록했습니다.
- 전자회로·디지털공학 정리에서는 64문항의 오분류·중복 분류를 교정했습니다. 증폭기 기초는 `증폭도·dB·입출력 임피던스`로 범위를 명확히 하고, 진법·보수연산과 디지털 코드·오류검출을 구분했습니다. 검토 범위와 문항별 근거는 `review/topic-organization-audit.json`에 기록했습니다.
- 1,100문제 모두 분류가 확정되어 있으며 분류 현황은 `review/classification-report.json`에서 확인할 수 있습니다.
- 1,100문제 모두 공식 정답을 적용했습니다. 국가직·지방직은 사이버국가고시센터, 군무원은 국방부 일반군무원 채용, 국회직은 국회사무처, 서울시는 서울특별시 지방공무원 임용시험 정답표를 기준으로 합니다.
- 국회직과 2014년 서울시는 5지선다, 나머지 시험은 4지선다로 문제별 선지 수를 표시합니다.
- 공식 정답 원본 PDF는 `official-answers/`에 보관하며, 2012년 이전 국가직·지방직 정답은 공식 사이트의 연도별 정답 조회 화면을 출처로 기록합니다.
- 현재 정답 미확정 문제는 없습니다.
- 정답 미확정 전체 목록: `review/unresolved-answers.csv`, `review/unresolved-answers.json`
- 시험별 20문제 한장 검수표: `review/contact-sheets/`
- 자동 감지 이슈: `review/crop-review.csv`, `review/build-report.json`

## 재생성

`tools/update_official_answers.py`가 확인한 공식 정답 데이터를 문제은행 형식으로 반영하고, `tools/build_bank.py`가 PDF 렌더링, OCR, 문제별 PNG 잘림, 검수표와 JSON을 만듭니다. OCR이 문제번호를 잘못 읽은 항목은 `data/anchor_overrides.json`, 여러 열에 이어지거나 큰 여백 때문에 자동 자르기가 어려운 항목은 `data/crop_overrides.json`에 보정 이유와 함께 보관됩니다.

세분류를 다시 적용하려면 `python3 tools/reclassify_questions.py`를 실행합니다. 이미지 대조로 확정한 예외는 스크립트의 `ID_OVERRIDES`와 `data/classification_corrections.json`에 있고, 인강 기준 최종 분류는 `data/curriculum_classifications.json`에 보존됩니다. 최종 분류를 우선 적용하며, 결과는 `data/classification_overrides.json`에도 저장되므로 문제 이미지를 재생성해도 분류가 유지됩니다. 브라우저에서 표시한 이미지 검수 결과는 로컬 저장소에 보존되며 JSON으로 내보낼 수 있습니다.

검토한 문항만 갱신하려면 `python3 tools/reclassify_questions.py --only seoul-2021-11`처럼 문항 ID를 지정합니다. 이 경우 지정하지 않은 문항의 분류·검수 상태는 보존하면서 화면용 데이터와 집계도 함께 갱신합니다. 등록된 문항은 인강 기준 최종 분류를 유지하며, 새 문항에는 기존 분류 규칙이 적용되므로 결과를 검토해야 합니다.
