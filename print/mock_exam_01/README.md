# 전자공학개론 창작 모의고사 제1회

- 문제지: `mock_exam_01_questions.pdf` — A4 세로 2단, 25문항, 5쪽. 각 페이지 왼쪽 열 위에서 아래로 읽은 다음 오른쪽 열로 진행한다.
- 정답지: `mock_exam_01_answers.pdf` — 정답표, 간단한 풀이, 난도 구성, 총 3쪽.
- 전 문항·수치·보기·벡터 회로도를 신규 작성했다. 기존 문제은행에는 추가하지 않았다.
- 각 4점, 100점 만점. 권장 시간 30분.
- 예상 난도 ★/★★/★★★/★★★★/★★★★★ = 9/10/5/1/0문항. 실제 정답률이 아닌 개념과 풀이 단계에 따른 판단이다.
- 난도 참고 표본: 지방직 2022~2026년 100문항을 각각 평가한 비율 38/39/19/4/0%.
- 수치·최소항 진리표·순서논리 상태 전이는 생성 스크립트의 별도 계산으로 검산했다. 개념 보기와 회로 연결은 수동 검토했다.

재생성: 저장소 루트에서 `python tools/build_mock_exam_01.py`.
필요 환경: PyMuPDF, fontTools, Noto Serif CJK 폰트 및 기존 PDF 생성 스크립트 의존성.
`questions.json`에는 정답과 예상 난도도 포함되어 있으므로 문제를 풀기 전에는 열지 않는다.
